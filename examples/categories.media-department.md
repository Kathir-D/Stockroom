# Categories: a media department

An example category tree, in the shape Admin → Categories → Import reads:
`##` is a Type, `###` a Category, `-` a Model. A line like this one is a note
and is ignored.

It is one real department's cupboard, kept as an example of the shape rather
than a list anybody else should copy. It is also exactly the tree `seed.sql`
loads in development, and `examples_test.go` holds the two to each other.
Six of the middle-level Categories (Studio Lights, Wired Mics, Bags, ...) were
invented for the seed so every branch has three levels; rename them freely.
